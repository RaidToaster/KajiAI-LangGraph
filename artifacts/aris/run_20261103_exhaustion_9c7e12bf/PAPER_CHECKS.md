# Manuscript validation

The final TeX and PDF are archived alongside the frozen protocol, evidence and review. The working manuscript and generated source ZIP are in evaluation. The first sandbox compile could not reach the existing TeX bundle, so compilation used the installed Tectonic and the host cache. An intermediate forced bibliography break produced an extra page. The final layout lets the bibliography flow in the existing IEEE columns.

Seven letter-sized pages compile with zero overfull boxes, zero unresolved citation markers, 11 references and all fonts embedded. Pages 1–5 match the inspected prior render by SHA-256. Pages 6–7 were re-rendered and inspected after inserting the live results. The final report is in paper-build-verified/pdf-validation.json. The unchanged repository suite passed 79 tests. No independent human citation annotation is claimed.
